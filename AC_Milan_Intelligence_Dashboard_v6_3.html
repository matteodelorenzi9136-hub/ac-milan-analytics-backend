🔐 Backend Contract
Payload richiesto dal Match Engine
Il frontend non conosce la API key. Il backend deve esporre GET /milan/scouting e restituire JSON con: opponent, date, venue, home, away, milanForm.form, opponentForm.form e quality. I dati possono provenire da football-data.org, API-Football o altro provider compatibile. Le credenziali restano esclusivamente lato server.
Architettura: Dashboard → Backend/Proxy → Provider calcio → dati normalizzati → Auto Scouting → Match Engine → Predictor.
